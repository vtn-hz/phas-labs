# Portfolio Project

## About

This project is Valentino Hernandez Pascual's personal/business portfolio. Goal: get
hired or land clients by presenting himself (including in person) at local businesses
and offering tech solutions tailored to what they actually need.

## Business name

**Phascual Labs** — the chosen name for the business/consultancy, a stylized spelling
("Ph") of the surname Pascual + "Labs". Use this name in any portfolio copy, pitch
materials, or branding for this project.

Personal handle used elsewhere: `vtn.hz` (also the git author identity, see global
`~/.claude/CLAUDE.md`).

## Architecture

Next.js (App Router) + TypeScript + Tailwind, fully static v1 (no backend/CMS/DB),
Spanish only, deployed on Vercel. Primary CTA is a WhatsApp deep link. Full
rationale and folder-by-folder responsibilities: `~/.claude/plans/jolly-dazzling-book.md`.

## Skills

- `prospect-audit` (`.claude/skills/prospect-audit/SKILL.md`) — given a business's
  URL, does passive technical + digital-presence recon and produces a pitch-ready
  brief (what tech they already have vs. gaps/opportunities) to prep for an
  in-person or cold outreach sales conversation. Not yet tested against a real URL.
